# SinMiedo-app
SinMiedo es una aplicación web enfocada en la prevención y detección temprana del bullying escolar.

La plataforma permite que estudiantes puedan enviar reportes de forma segura y anónima para comunicar situaciones de:

acoso escolar,
ciberbullying,
amenazas,
exclusión social,
violencia verbal o física.

El objetivo principal es ofrecer una herramienta digital que facilite la comunicación entre estudiantes y centros educativos, promoviendo un entorno más seguro.
